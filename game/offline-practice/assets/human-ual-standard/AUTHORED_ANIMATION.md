# Local authored animation

HumanBasketball.glb is derived from the accompanying CC0 Universal Animation
Library Standard model by Quaternius. Original source and license remain in
License.txt and README.txt; HumanDiagnostic.glb is preserved byte-for-byte.

Authored_Basketball_v1 adds four local arm-rotation key poses generated by
tool/author_basketball.dart using an offline CCD solver. It retains the original
rig, geometry, materials and idle-body tracks. It is not a downloaded basketball
motion-capture animation. CCD runs only during asset authoring, not gameplay.

Reproduction: from game/offline-practice, run dart run tool/author_basketball.dart.
The generated asset still requires visual review in the pinned Scene renderer.
